# Sponsor Narrative

Guided 9-part annual sponsorship proposal builder. Enter market problem,
regulatory hooks, program themes, three sponsorship options, and success
measures on the left — get a copy-ready proposal scaffold on the right, with
the guardrails (no pricing, problem-first, sponsor name 2–3×, outcomes not
impressions) enforced live.

Data never leaves the browser: drafts autosave to localStorage. No backend, no
accounts. Structure follows the 9-part annual proposal narrative used for
long-form sponsorship/partnership conversations.
